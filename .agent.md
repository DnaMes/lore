# Lore — Agent Context

Local-first archive and shared agent memory for AI coding sessions, with MCP integration.

> Product/CLI = **Lore** (`lore`). Python import package = `lore`
> (deliberately not renamed).

## Purpose
Two things in one: (1) an **archive** that collects and unifies chat histories
from Claude Code, OpenCode, Gemini CLI, Cursor, Codex, VSCode Copilot, and
Antigravity; (2) a **shared agent memory** — a cross-tool knowledge store agents
write to and recall from with keyword + semantic search and provenance.
Local-first, no cloud.

## Structure
- lore/ — Python Package (CLI, Web UI, MCP)
- tests/ — Pytest Suite
- docs/ — Documentation
- docker-compose.yml — Local Stack
